# Kalkulator Transformasi Geometri (C++)

Program sederhana untuk menghitung **translasi** dan **refleksi** pada titik koordinat 2D.  
Dibuat dengan bahasa **C++** sebagai latihan logika pemrograman dan implementasi transformasi geometri dasar.

---

## 🚀 Fitur
- Menginput titik (x, y)
- Melakukan translasi (geser) dengan nilai dx, dy
- Melakukan refleksi (pencerminan)
